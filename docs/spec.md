# DM 캠페인 관리자 신청 페이지 — 설계 메모

작성일 2026-09-01

## 1. 기능 파악 (출처: 두레이 `META-InstagramMessenger/388`)

과제명: **DM 캠페인 관리자 - 계정 통합 관리** (최종 버전 피그마 V3.2 / 어드민 V6.3, 기획 이유경)

### 원본 요구사항

- B2B 관리자의 관리중인 인플루언서 계정 리스트를 통합 관리
- 인플루언서 통합 대리 결제
- 인플루언서 데이터 통합 또는 개별 조회 (소재단위)

### 댓글에서 확정된 운영 규칙

| 항목 | 확정 내용 |
|---|---|
| 멤버 초대 | **이메일 전용.** 대표자가 이메일 주소를 추가하면 초대 메일 발송. 알림톡 채널 제외 |
| 멤버 로그인 | **조직 ID + 본인 이메일.** 대표관리자 이메일 + 본인 이메일 방식을 검토했으나, 대표관리자의 개인정보(이메일)가 멤버에게 노출되는 부담이 있어 조직 ID 입력으로 변경 |
| 약관 | 별도 문서 존재 — `이용약관 제8장 캠페인관리자 특약`, `캠페인관리자 개인정보 수집 및 이용 동의`, `캠페인관리자 운영정책` |

### 영업 관점 정리 (출처: `socialbiz-app/docs/통합관리자_영업소개자료.md`)

- 내부 명칭 **통합관리자(캠페인용)** = 제품 기능명 **소셜비즈 부스트(다계정 관리)** — 동일 확인됨
- 단일계정 제품과의 차이: 단일계정은 인스타 1계정만 댓글→DM 자동화. 통합관리자는 소셜비즈 계정 1개에 **여러 인스타 계정을 연동**하고 **통합 대시보드**로 함께 조회
- 판매 형태: **Custom 계약**. 연동 계정 수·기간·컨택 규모에 따라 협의
- 타겟: 대기업 마케팅팀 / 마케팅 대행사 / 멀티계정 인플루언서·MCN

## 2. 이 페이지의 역할

엔터프라이즈·비즈니스 요금제 아웃바운드 메일(현재 `email_automation` · `socialbiz-mailer` 로 자동 발송 중)의
착지 페이지 중 하나. **콜드 트래픽이 기능을 이해한 상태로 전화 상담까지 오게 하는 것**이 목표.

기존 착지 페이지와의 역할 분담:

| 페이지 | 역할 |
|---|---|
| `socialbiz-consulting` | 인스타 DM 자동화 일반 무료 상담 (단일 계정 포함) |
| `enterprise-setting` | 이미 계약한 고객의 세팅 대행 신청 |
| **`dm-campaign-manager`** (이 페이지) | **다계정 통합 운영이 필요한 고객의 도입 신청** |

## 3. 설계 결정

| 결정 | 선택 | 이유 |
|---|---|---|
| 배포 | 새 저장소 + GitHub Pages, 빌드 없는 단일 HTML | 기존 두 페이지와 동일 패턴. 단독 광고 랜딩으로도 재사용 가능 |
| 페이지 구성 | 소개 랜딩 + 하단 신청 폼 | 콜드 트래픽 대상. 전화 전에 기능 이해가 끝나 있어야 상담 품질이 올라감 |
| 접수 | FormSubmit.co 메일 + Apps Script 구글시트 | `enterprise-setting` 에서 검증된 조합. 메일은 즉시성, 시트는 리드 축적 |
| 완료 판정 | **메일 전송 성공 시에만** 완료 화면 | 시트 적재는 `no-cors` 라 결과를 알 수 없음. 메일이 실패했는데 완료로 보이면 리드가 조용히 사라짐 |
| 요금 표기 | "별도 협의"만 | Custom 계약이라 일괄 금액이 없음. 숫자를 박으면 앵커링 위험 |
| 디자인 | 기존 SocialBiz 토큰 승계 (`#7c3aed → #2563eb`) | 같은 메일에서 나가는 자매 페이지들과 시각적으로 한 세트여야 함 |

기존 페이지 대비 개선한 점: Pretendard 웹폰트 실제 로드(기존은 `font-family` 에 이름만 있고 미로드),
스크롤 리빌(`prefers-reduced-motion` 존중), OG 메타, 개인정보 수집·이용 동의 필수화.

## 4. 수집 항목과 근거

**필수** — 회사/브랜드명, 담당자 성함, 직책/부서, 연락처, 이메일, 문의 내용
→ 요청받은 항목. 이메일은 견적 회신·조직 초대 발송에 필요해 추가.

**선택 (전화 전 리드 퀄리파이용)**

| 항목 | 왜 받는가 |
|---|---|
| 회사 유형 (브랜드사/대행사/MCN/커머스) | 세일즈 메시지가 유형별로 갈림 |
| 통합 관리 예정 계정 수 | **견적을 좌우하는 단일 최대 변수** |
| 도입 희망 시기 | 우선순위 정렬 |
| 현재 소셜비즈 이용 여부 | 신규 계약 / 업그레이드 분기 |
| 관심 기능 (체크) | 통화 첫 3분의 화제를 정해 줌 |
| 통화 가능 시간대 | 직접 전화로 컨택하므로 연결률에 직결 |

**필수 동의** — 개인정보 수집·이용 동의.
현재 문구는 **임시 표준 문구**다. 두레이 첨부 `소셜비즈_캠페인관리자_개인정보 수집 및 이용 동의_V2.0.docx`
확정본으로 교체해야 한다. `index.html` 해당 위치에 `⚠️ 법무 확정본 교체 필요` 주석이 있다.
