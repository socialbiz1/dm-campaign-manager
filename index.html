HOW IT WORKS

어떻게 동작하나요

대표관리자 1명이 세팅하고, 각 계정은 연결 후 게시만 하면 됩니다.

1

계정 초대

대표관리자가 함께 운영할 인플루언서·담당자의 이메일 주소를 추가하면 초대 메일이 발송됩니다. 인스타그램 계정을 여러 개 등록해 하나의 조직으로 묶습니다.

초대받은 멤버는 조직 ID + 본인 이메일로 로그인합니다. 대표관리자의 이메일 주소는 멤버에게 노출되지 않습니다.
2

통합 대리 결제

계정마다 개별 결제할 필요가 없습니다. 대표관리자가 연동된 전체 계정의 이용료를 한 번에 결제합니다. 인플루언서에게 결제를 요청하거나 영수증을 따로 모을 일이 없습니다.

3

댓글 · DM 템플릿 일괄 배포

미리 세팅해 둔 댓글 자동 답장 · DM 자동화 시나리오를 선택한 계정들에 한 번에 배포합니다. 계정마다 처음부터 다시 세팅하던 작업이 한 번으로 줄어듭니다.

4

각 계정은 연결하고 게시만

배포받은 인플루언서는 본인 인스타그램 계정을 연결하고 게시하기만 하면 자동화가 바로 시작됩니다. 세팅 방법을 한 명씩 안내할 필요가 없습니다.

5

성과는 통합으로, 필요하면 개별로

전체 계정 성과를 합산해서 보거나, 소재 단위로 계정별 성과를 분해해서 봅니다. 캠페인 리포트를 계정마다 열어 취합할 필요가 없습니다.

SAFETY

계정이 많을수록,
안전한 구조가 더 중요해집니다

✓

메타(Instagram) 공식 API 기반입니다. 계정 비밀번호를 넘겨받는 비공식 자동화 툴과 근본적으로 구조가 다릅니다.

✓

모든 발송은 고객이 먼저 반응(댓글·스토리·DM)한 뒤에 나갑니다. 무작위 콜드 DM은 지원하지 않습니다 — 계정 정지의 주원인이기 때문입니다.

✓

안전 발송 한도(시간당 발송량, 동일 문구 반복 방지)를 시스템이 자동으로 지킵니다.

✓

연결할 계정은 프로페셔널(비즈니스·크리에이터) 계정이어야 하며, 페이스북 페이지 연결이 필요합니다. 연동은 공식 OAuth 방식이라 비밀번호를 공유하지 않습니다.
